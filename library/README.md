# 动效库总表

由 `tools/catalog.py` 生成，别手改。标签取值和含义见 `tags.json`。

- **用途**：这句话在做什么，挑动效先看它。一个动效最多 3 个用途。
- **分量**：底层（不算数量）/ 小（脸完整露出）/ 大（全屏、盖脸、转场、版式大变）。
- **组**：长得像的归一组，一条视频每组最多用一个。
- **位置**：上方 / 中部 / 胸口 / 下方 / 全屏 / 环绕 / 整体（只动镜头或调色），同一时间别两个东西挤一个位置。

分量：底层 10 · 小 54 · 大 60
