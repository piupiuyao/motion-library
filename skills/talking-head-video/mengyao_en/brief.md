# 创意简报 · Mengyao「ToneBird 中文口播」（只用库里的动效）

## 看片
- 人：年轻女生，米色无袖长裙，户外天桥，背后是纽约街景和楼，阳光很好。语气亲切、像跟朋友聊天。
- 画面空位：头顶左边一大块天空（上方安全）；人居中，脸在画面上 1/3；胸前裙子是干净的大块浅色。
- 颜色：取自 tonebird 官网，主色蓝紫 #6074dd，第二色洋红。

## 核心
- 一句话：「回消息不该需要攒勇气。」
- 情绪：共鸣（不知道怎么开口）→ 纠结（写了删删了写）→ 出现解决办法（ToneBird）→ 怎么用 → 落到「更像你」→ 收尾品牌。
- 主风格：简洁商务（干净卡片、清单），可混「通用」。户外自然光的片子，不用黑底、霓虹、漫画。

## 每个时刻（全部来自动效库）
| 时刻 | 用库里的 | 为什么 |
|---|---|---|
| 开头「消息看到了，也知道该回」 | 原生白框字 native_textbox | 像朋友发来的快拍文字，接地气，放在头顶天空的位置 |
| 「写了删、删了写」 | 逐条划掉清单 strike_list | 字出现就被划掉，正好就是「写了又删」的动作 |
| 「Gmail、Slack、WhatsApp」 | 白卡图标环绕 icon_cards | 说到哪个弹哪个真 logo，围在四周不挡脸 |
| 「礼貌拒绝、推进合作、自然地跟进」 | 清单打勾 checklist | 三个用法，说一个勾一个，全片唯一的干货清单 |
| 「让回复更像你自己」 | 推近 push_in | 走心的一句，只推近，不加东西 |
| 「攒够勇气、腾出时间」 | 两字分立头侧 split_word_head | 两个关键词一左一右夹着脸，点题前的停顿 |
| 结尾「这就是 ToneBird」 | 结尾标题卡 end_title | 品牌收尾 |

数量：大 2（清单、结尾卡）· 小 3（不算开头钩子）· 挡脸 0，在「适中」档以内。

## 自查时改过的
- 一开始在「AI 回复助手」上放了关键词放大：紧贴在划掉清单后面，0 秒间隔太挤 → 去掉，交给字幕。
- 规则检查说划掉清单和打勾清单是同一组：划掉清单表达的是「否定/写错了」，不是步骤清单 → 库里把它改到「对错标签」组。
