# 通用口播剪辑 skill：计划表（10-26 草稿）

## 目标

谁录了一段口播，交给 AI，AI 剪出一条约 1 分钟的竖屏短视频（可以另出横屏）：
去停顿和口误 → 给每句话判断类型 → 按类型套一个「抠图模板」 → 加字幕、配乐 → 出片。
风格不写死，换一套模板皮肤就换一种风格。最后放进 amplifthq/Clico 仓库，和 Helen 那两个视频 skill 放在一起。

## 整体思路（和 TT Symphony 的模板一个路子）

- **规则层**（视频 A）：这句话在说什么 → 该用哪类画面。通用，不跟风格走。
- **模板层**（视频 B + A 里的画面）：每个模板是一套固定的分层画面（背景 / 人像 / 前景 / 文字），把抠出来的人像放进去就能出画面。
- **皮肤**：同一个模板换颜色、字体、背景素材，就是另一种风格。先做两套：克制高级风（像 A）、花哨网感风（像 B）。
