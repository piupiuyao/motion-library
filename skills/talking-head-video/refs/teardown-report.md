来源：Monica 给的两条微信视频号，用户手机录屏。
做法：Gemini 额度用完，改为每秒抽一帧人工看 + 本地 whisper 转写。whisper 有错字，下面文字已按画面里的字幕校正。

## 视频 A：「告别廉价口播」（剪辑师白菜，94_1793056051.mp4，20 秒）

**一句话**：一句话一条规则，讲「这句话在说什么内容 → 画面就怎么处理」，每条规则当场演示一遍。

**版式**：顶部固定大标题 BAI CAI EDITING + 绿色小字「告别廉价口播」，中间是演示画面，左边一个小窗是原始素材做对照。

| 时间 | 说的内容 | 画面处理 |
|------|----------|----------|
| 0–2s | 剪辑技巧，轻松解决 | 开头大特写 + 大标题字 |
| 2–4s | 核心诉求 → **放大字幕** | 字幕里关键词换颜色、放大 |
| 4–6.5s | 吐槽行业痛点 → **变黑白、缩小画面**（画面字幕写「就变音缩小画面」，可能还配了变声） | 画面去色，缩进黑底小框 |
| 6.5–9s | 展示 B-roll 细节 → **加蒙版** | B-roll 全屏（地球），人缩进底部圆形小窗 |
| 9–11s | 真实资料 → **资料引入** | 新闻截图一张张飞入叠放，人在左上小圆窗 |
| 11–13s | 输出观点 → **抠像出镜** | 人抠出来放在深色背景上，旁边配「重点」文字卡 |
| 13–15s | 罗列数据 → **配图表** | 环形图（88%、50%）叠在人前面 |
| 15–19s | 情绪拉升 → **关键帧推近** | 镜头慢慢推近人脸 |
| 19–20s | 口播视频 | 结尾标题卡「口播视频 告别廉价」 |

**能直接拿来用的**：这是一张「内容类型 → 画面处理」对照表。我们的 skill 列镜头表时，可以先给每句话标上类型（观点 / 吐槽 / 数据 / 资料 / 细节 / 情绪高点），再按表选处理方式。比原来那条死规则「连续露脸不超过 10 秒」更好用，因为它说得清每次该换成什么。

## 视频 B：「4 套剪辑手法打破扁平画面」（我李哥豆儿，95_1793056112.mp4，43 秒）

**一句话**：口播画面扁平、没看点，解决办法是做出**空间层次**（前景、人、背景分开），一共演示 4 种。

**开头钩子（0–4s）**：「你的口播画面扁平、无看点」，配黑白画面 + 白底大字「无看点」，先戳痛点，再弹出「4 套剪辑手法」「打破画面」「用空间感营造网感」。

| 时间 | 手法 | 画面怎么做的 |
|------|------|--------------|
| 4–6s | 第一种：**蒙版制造视觉焦点** | 白色虚线框、虚线圆圈住要看的部位，跟着话移动；口号「哪里需要看哪里，观众视线由你掌控」 |
| 6–12s | 第二种：**背景层和人像层之间插边框** | 换波点背景，人放进拍立得相框，贴纸错开叠放，出立体感（字：背景层 / 人像层 / 错落分层 / 立马显现） |
| 12–19s | 第三种：**文字形变和位置动画做纵深** | 超大黄字一部分压在人前、一部分藏在人后（字：形变 / 位置 / 改变画面纵深 / 多层） |
| 19–30s | 第四种：**抠出人像 + 背景纸 + 分层演示素材** | 人抠出加白描边，背景换成皱纸，相机、照片等素材从两边分层插入（字：插入背景纸 / 空间效果立刻拉满） |
| 30–40s | 总结 | 「记住，塑造画面空间是摆脱平庸剪辑的关键一步」，配扫描线质感 + 大字 |
| 40–43s | 结尾 | 「学会了去练，不会就问」 |

**全片共同手法**：
- 每段换一次背景（紫色霓虹、波点、格子、皱纸），段落一看就分得开
- 人物抠像几乎全程加白色或彩色描边，像贴纸
- 字幕不是一行小字，而是每句挑 2–3 个关键词做成超大花字，位置到处变

**能直接拿来用的**：4 种空间手法可以做成 skill 里的「画面处理库」，和视频 A 的对照表配合：A 管「这句该不该换画面、换成哪类」，B 管「换的时候怎么做出层次」。

## 两条对比

| | A（白菜） | B（李哥豆儿） |
|---|---|---|
| 讲什么 | 按内容选处理方式 | 怎么做出空间层次 |
| 节奏 | 约 2 秒一条规则，极快 | 约 5–7 秒一种手法 |
| 风格 | 偏高级、克制（深色、绿色点缀） | 偏花哨、网感（大花字、贴纸、换背景） |
| 对 skill 的用处 | 决定每句话怎么剪 | 提供具体的画面做法 |

两条风格差很多，正好说明 skill 应该**不限风格**：规则层（A）通用，画面层（B）可以换皮。

## 我们现在做得到的 / 要补的

- 现在就能做：放大关键词字幕、黑白 + 缩小、关键帧推近、B-roll + 圆形小窗、图表叠加、结尾标题卡、换背景（这些用 HyperFrames + ffmpeg 都行）

- 要补：资料截图飞入、文字压在人前人后（需要抠图后分层，跟上面同一件事）
