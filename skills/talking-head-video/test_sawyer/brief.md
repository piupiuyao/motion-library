# 创意简报 · Sawyer「忘掉的订阅」

## 看片
- 人：沉稳的播客男生，灰墙、藏青 T 恤、棕皮椅、面前一支麦克风。语气是朋友讲理财，不是喊口号。
- 画面空位：右边被麦克风占了，左上方是空墙 → 图形放左上，放在人身后（抠像），挡到头发就藏在后面。
- 颜色：他身上没有亮色（深藏青太暗取不出），所以不跟衣服走，跟题材走：银行账单式的白纸 + 红字。

## 核心
- 一句话：「订阅不贵，忘了它才贵。」
- 情绪：扎心 → 给办法 → 点题 → 算账倒吸一口气 → 评论领清单。

## 创意：一张收据贯穿全片
| 时刻 | 画面 | 为什么 |
|---|---|---|
| 开头「4 subscriptions you forgot」 | 左上吐出一张收据，四行是空的虚线 | 钩子；空行 = 被忘掉的东西 |
| 「$212」 | 合计打出红色 $212 | 第一个扎心数字 |
| Netflix / Spotify / Disney+ / gym | 空行逐个补全，带 logo；Disney+ 没有 logo 就只打字 | 说什么补什么，收据上打字比贴 logo 更像真账单 |
| 「search」 | 标题被红色荧光划一下 | 第一步：搜 subscription |
| 「cancel」 | 四项被红线逐条划掉 | 第二步 |
| 「move the money」 | $212 划掉，出绿色「→ SAVINGS +$212」 | 第三步，钱从支出变存款 |
| 「payday」 | 收据撕下掉落 | 前半段收尾，给金句腾地方 |
| 「A subscription isn't expensive. Forgetting it is.」 | 背景压暗，人亮着，身后三行大字，最后一行红色 | 全片最重要的一句，故意做得最空 |
| 「just coffee money」→「$2,500 a year」 | 小票上一杯咖啡，变成满满一格子咖啡，合计滚到 $2,500 | 把轻描淡写变成倒吸一口气 |
| 「comment money」 | 一张小票：COMMENT / MONEY + 条形码 | 和开头收据首尾呼应 |

## 用到的动效
- 库里的：压暗背景大字（dim_backdrop_words），按这条改了字号和位置。
- 这条现做的（test_sawyer/effects/）：receipt_story 收据串场、coffee_money 咖啡钱算账、receipt_cta 收据结尾。

## 自查时改过的
- 收据第一次挡住了半张脸 → 缩小、挪到最左、放到人身后。
- 收据第二次被头挡住了 $212 → 收窄，保证数字露在外面。
- 金句最后一行被头挡住 → 三行整体上移、字号缩小。
- 结尾小票字太小（字体写法出错，回退成默认小字）→ 修好。
