# 创意简报 · Sawyer「忘掉的订阅」（只用库里的动效）

## 看片
- 人：沉稳的播客男生，灰墙、藏青 T 恤、棕皮椅、面前一支麦克风。语气是朋友讲理财，不是喊口号。
- 画面空位：右边被麦克风占了，头顶和左右两侧上方是空墙；胸口右边有麦克风，胸前的东西要偏左或居中偏上。
- 颜色：衣服太暗取不出颜色 → 按题材定：绿色（钱、省下来），字幕高亮和打勾都用它。

## 核心
- 一句话：「订阅不贵，忘了它才贵。」
- 情绪：扎心 → 点名 → 给办法 → 点题 → 算账倒吸一口气 → 评论领清单。
- 整体气质：平静、可信、像朋友提醒。不用黑白大字、震屏、漫画这类喊口号的效果。
