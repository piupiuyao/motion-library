# 照片变数字人 + 一稿出多语言口播：详细方案

2026-11-02 · 接着 10-28 的调研（`research/ai-avatar.md`）往下写 · 只查了资料，还没实测 · 标「⚠」的是只在第三方网站看到、官方没写清的

## 要做成什么

```
一张全身照 + 一份中文稿
        │
        ├─ 翻译：中文稿 → 英文 / 日文 / 韩文稿（AI 翻译 + 人看一眼）
        │
        ├─ 配音：每种语言用「同一个人的克隆声音」读出来
        │
        ├─ 数字人：照片 + 每种语言的音频 → 每种语言一条会说话的视频（嘴型天然对得上）
        │
        └─ 剪辑：我们的一键成片，每种语言一条——字幕、动效里的字都是这种语言
                    ↓
          中文版 · 英文版 · 日文版 · 韩文版
```

关键点：**导演只做一次**（看片、写简报、挑哪句配哪个动效），然后每种语言各出一条，只是字换了、时间跟着那种语言的语速变。不是做四次。

---

## 一、照片变数字人：给一张全身照能不能做？

**能做，但有几件事要先知道。**

### 1. 全身照能用，但出来的画面不一定是全身

- HeyGen 照片数字人（Avatar IV）官方说正脸、半身、全身照都能用。可灵数字人 2.0、字节的 OmniHuman 也都是一张图就能出。
- 问题是：**竖屏口播一般是胸口以上的景别**。全身照直接做，人在画面里很小，脸只占一点：
  - 嘴型、表情的细节会变差（脸越小，AI 越容易糊）；
  - 我们的动效默认人脸在画面上三分之一，很多卡片、字是围着脸摆的，全身画面要重新排。
- **建议**：你给全身照，我们做两版——
  - **主力：裁成半身**（胸口以上或腰以上）去生成，口播效果最好；
  - **偶尔用：全身版**，用在开场亮相、穿搭/产品展示这种需要看到全身的镜头。

### 2. 手和身体动作是现在最大的差距

| 服务 | 一张照片能动到哪 | 口碑（都是网上评测，⚠ 没有独立对比） |
|---|---|---|
| **HeyGen Avatar IV** | 头、表情、上半身，有手势 | 最稳、接口最成熟；动作偏保守 |
| **可灵数字人 2.0**（快手） | 头、上半身，手势比 1.0 版稳很多 | 很稳定、少出错；有评测说手势重复、表情偏僵 |
| **OmniHuman 2.0**（字节，10 月刚出 ⚠） | 头、肩膀、**手势跟着话的意思动**，还能用文字指定动作（比如说到重点抬手） | 动作最丰富；有评测说手势有时会变形、画质有压缩痕迹 |
| HeyGen Avatar V（数字分身） | 要本人录 15 秒视频，不是照片 | 最像真人，适合长期固定用的「品牌脸」 |

结论：**光看资料分不出谁最好，必须拿同一张照片、同一段音频实测对比。**

### 3. 到底贵不贵？——按「一条 60 秒视频、一种语言」算

| 做法 | 一分钟大约 | 一条 60 秒 4 种语言 | 说明 |
|---|---|---|---|
| HeyGen 网页版 Creator 套餐（$29/月，600 积分） | 约 **$0.8**（照片数字人 16 积分/分钟 ⚠ 有的地方写 20） | 约 $3.2 | 最便宜，但要人在网页上点，不能自动化；一个月约 30–37 分钟 |
| HeyGen API（按量付费，最低充 $5） | 约 **$2.3–3** ⚠（4K 约 $4） | 约 $9–12 | 能接进我们的自动流程 |
| 可灵数字人 2.0（经第三方接口） | 标准版约 $3.4，Pro 约 $5–7 ⚠ | 约 $14–28 | 国产，中文语境自然 |
| OmniHuman 2.0 | 价格各平台不一，大致 $8–15 ⚠ | 约 $32–60 | 动作最丰富，也最贵 |
| 配音（ElevenLabs 克隆声音） | 不到 $0.5 | 约 $2 | 可以忽略 |

**所以单看钱，其实没有想象中那么贵**：一条 60 秒、四种语言，用 HeyGen 大概 **$5–15（约 35–100 元）**。真正「贵」的是：

- **试错**：一张照片要多试几次才知道哪个服务、哪种裁法好看，前期要预留测试费（建议 $50–100）。
- **要高质量的那档**：OmniHuman / Avatar V / 4K 会贵 3–5 倍。
- **量大以后**：一天几十条、每条四种语言，每月就是几百美元，到时候再谈企业价或换开源方案。

### 4. 用谁的脸——必须有授权

- 照片数字人平台**不核验**照片里的人是否同意，法律责任在我们。
- 用真人的脸和声音：要有书面授权（写明：肖像 + 声音、用于 AI 生成、可商用、期限、几种语言）。
- 发抖音 / TikTok 要打「AI 生成」标识（国内 2025-09-01 起是法规要求）。

## 二、一稿出多语言：中文稿 → 英 / 日 / 韩口播

### 1. 翻译

- AI 翻译（Claude 就能做）初稿很好，但**口播稿不是逐字翻**：要改成那种语言的口语说法、长度差不多（日文、韩文同样意思往往更长或更短）。
- 建议每种语言**找一个懂的人扫一眼**，尤其是梗、品牌名、数字单位（万 / 千、人民币 / 美元 / 日元）。

### 2. 配音：同一个人的声音说四种语言

- ElevenLabs 支持中英日韩（新版 70+ 种语言）。用一段中文录音克隆后，**理论上能用同一个音色说英日韩**。
- 但官方建议「要说哪种语言，就用哪种语言录音来克隆」——跨语言时**可能带口音**（比如英文带中文腔）。这个必须实测。
- 退路：
  - 本人能说一点英文的话，再录一段英文样本单独克隆；
  - 或者外语版用一个「音色接近的母语声音」，不追求完全是本人。
- 中文版：另外对比 MiniMax 海螺、阿里 CosyVoice（大家普遍说中文更自然）。

### 3. 嘴型

- 因为每种语言都是**重新生成**数字人（照片 + 那种语言的音频），嘴型天然对得上，**不需要另外的「翻译对口型」服务**。
- 「翻译对口型」只在**真人拍的口播**要翻成外语时才需要（HeyGen 视频翻译约 $2/分钟，日韩这种大语种口碑还行）。

### 4. 我们的动效和字幕要跟着语言变——要改什么

我查了一下库里现在的情况：

| 问题 | 现在 | 要改成 |
|---|---|---|
| **字体** | 默认英文字体，中文会退到苹方（简体），**日文、韩文没有专门的字体** | 按语言换整套字体：中文 苹方 / 思源黑体，日文 Hiragino / Noto Sans JP，韩文 Apple SD Gothic / Noto Sans KR；花字、手写风的也要各备一套 |
| **全大写、字间距** | **42 个动效**会把字转成全大写或拉宽字间距（英文才好看） | 中日韩自动关掉大写，字间距改回正常 |
| **按空格拆词** | 少数动效按空格拆词（比如四角分字、脸旁分字、逐词弹跳） | 中日韩没有空格，要改成按字 / 按词组拆（新做的 3 个已经支持，老的要补） |
| **字幕断行、高亮** | 字幕按英文单词出、按单词高亮 | 中日韩按字出、按词组高亮，不能把一个词从中间断开 |
| **文字长度** | 卡片、标签宽度是按英文长度调的 | 同一句话日文常更长、中文更短，卡片要自动缩放，不溢出 |
| **转写** | whisper 转写，可选 `--lang en/zh` | 既然有稿子，**直接用稿子对齐音频**，不靠转写猜字——四种语言都不会出错字 |
| **镜头表** | 按「第几个词到第几个词」定位 | 改成按「第几句」定位：导演一次，每种语言按自己那句的时间放动效 |
| **动效里的字** | 导演时填英文原话 | 导演时填原文，再按语言翻译成对应的字（比如「SYSTEM」→「系统」「システム」「시스템」） |

这些都是我们自己代码里的事，**不花钱，但要花工夫**。建议先挑最常用的 20–30 个动效做好多语言，其余的慢慢补；还没支持的语言就自动不选那个动效。

## 三、建议的试验顺序

| 步骤 | 做什么 | 要你做的 | 预计花费 |
|---|---|---|---|
| 1 | 准备一张全身照（正面、光线好、不戴墨镜、手自然下垂或轻放身前）+ 一份 60 秒中文稿 + 1–2 分钟本人中文录音 | 提供照片和录音（要本人同意） | 0 |
| 2 | 我把中文稿翻成英 / 日 / 韩，你找人扫一眼 | 找人看译稿 | 0 |
| 3 | ElevenLabs 克隆声音，出四种语言的音频；中文另出 MiniMax 一版做对比 | 注册 + 开 $5 套餐 | $5 |
| 4 | 同一张照片分别「裁半身」和「全身」，同一段英文音频喂给 HeyGen、可灵、OmniHuman，对比 | 注册 + 付费（HeyGen $29 / 可灵、OmniHuman 先用免费积分） | $29–60 |
| 5 | 挑出最好的那个，四种语言各出一条 | — | 包含在上面 |
| 6 | 同时我改剪辑：按语言换字体、关大写、按句定位、用稿子对齐；先让 20–30 个常用动效支持多语言 | 不用 | 0 |
| 7 | 四条都丢进一键成片，出四个语言的成片给你看 | 看片挑刺 | 0 |

**总共大约 $35–65 能跑完一整轮。** 注册、登录、付款要你来；其余的我做。

## 四、要你定的

1. **用谁的照片和声音？**（要有本人同意；你自己最方便）
2. **四种语言都要，还是先中英两种跑通再加日韩？**（建议先中英，日韩紧接着加——难点在字体和断行，做一次就都通了）
3. **预算 $35–65 能不能批？**
4. **译稿谁来看？** 日文、韩文需要懂的人扫一眼。
